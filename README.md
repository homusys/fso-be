# Full Stack Open — Backend

This repository contains my backend exercises and projects from the [Full Stack Open](https://fullstackopen.com/en/) course by the University of Helsinki.

The projects focus on backend development, including building REST APIs, handling HTTP requests, managing data, and connecting applications to databases.

## Technologies

Technologies covered throughout the course include:

- JavaScript
- Node.js
- Express
- REST APIs
- MongoDB
- Mongoose
- Data validation
- Error handling
- Testing
- TypeScript

_Technologies listed may vary depending on the exercises and course parts completed._

## Repository Structure

Projects and exercises are organized by course part and exercise.

## Goals

- Practice backend development using Node.js and Express.
- Build and maintain REST APIs.
- Learn database integration and data management.
- Handle HTTP requests, responses, and errors.
- Improve code organization, testing, and backend development practices.
- Build practical backend projects while progressing through the course.
